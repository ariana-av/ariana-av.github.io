MIPS Slot Machine

CS240 Computer Organization · MIPS assembly language · MARS

MIPS AssemblyMARSGameBitmap DisplayKeyboard MMIO

Overview

MIPS Slot Machine is a slot machine game written in MIPS assembly language and coded in the MARS simulator. I developed it as a project for my Computer Organization class, CS240. The game uses simulated credits only, and no real money is involved. It renders the reels, credit balance, controls and results on the Bitmap Display, and it receives player input through the Keyboard and Display MMIO Simulator.

Gameplay

  • The player begins with 20 simulated credits.
  • Each spin of the three reels costs 1 credit.
  • Two matching numbers return 2 credits.
  • Three matching numbers return 10 credits.

Controls

KeyAction
SSpin the three reels
RReset the game
QQuit the game

Setup instructions

To run the game in MARS, open the Bitmap Display and the Keyboard and Display MMIO Simulator from the Tools menu. For the best experience, place the two windows side by side. Configure the Bitmap Display with the following settings, then connect both tools to the program before running it:

SettingValue
Unit width and height in pixels8 by 8
Display width and height in pixels512 by 512
Base address for display0x10008000 ($gp)

Once the program is assembled and running, type your commands into the Keyboard MMIO Simulator. Press S to spin the reels.

Technical highlights

  • Written entirely in MIPS assembly language and developed in MARS
  • Draws the reels, credit balance, controls and results directly to the Bitmap Display, starting at base address 0x10008000
  • Reads keyboard input through memory-mapped I/O (MMIO)
  • Implements game logic for credits, spin costs, payouts and reset

Course context

This project was completed for CS240, Computer Organization, at San Diego State University. It applied low-level programming concepts, including memory-mapped I/O and direct control of a display through memory addresses.
