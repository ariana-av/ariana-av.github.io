# Portfolio website (plain HTML/CSS/JS, no build step)

Open `index.html` to preview. Deploy by uploading to a repo named `USERNAME.github.io`
(Settings -> Pages -> Deploy from a branch -> main / root).

## Edit
| What | Where |
|------|-------|
| Short intro paragraph | `index.html` (marked with an EDIT comment) |
| Portfolio cards | `index.html` (`<article class="card">` blocks) |
| Project pages | `project-one.html` etc. |
| Resume / CV | `resume.html`, `cv.html` |
| Colors | top of `assets/css/main.css` |

Name, bio and links also appear in the sidebar of every page. Use Find & Replace across the folder
(Ctrl/Cmd + Shift + H in VS Code).

Light/dark mode follows each visitor's device setting automatically.
